FORMULARIOS EN HTML

¿Qué es un formulario?

Un formulario sirve para ingresar información en una página web, como el nombre, la edad o el correo electrónico.

Ejemplo de formulario

Completa los datos. Si falta algo, la página te mostrará un mensaje claro; si todo está bien, confirmará el envío.

Características

  • Permiten escribir información.
  • Organizan los datos del usuario.
  • Se utilizan en páginas web.
  • Pueden validarse antes de enviarse, con HTML y con JavaScript.

Elementos de un formulario

ElementoFunción
labelDescribe un campo y mejora la accesibilidad.
inputRecibe texto, números, correos, casillas y botones.
selectPermite elegir una opción de una lista.
textareaRecibe textos largos.
fieldset y legendAgrupan campos relacionados con un título.

GET y POST

MétodoFunción
GETEnvía datos mediante la dirección web.
POSTEnvía datos dentro de una solicitud.
