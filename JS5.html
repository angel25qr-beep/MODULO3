5. Aplicación de JavaScript en HTML

¿Qué es?

JavaScript puede integrarse en un documento HTML mediante la etiqueta script. También puede conectarse desde un archivo externo con el atributo src.

¿Para qué sirve?

La integración permite que los botones respondan, que los formularios se validen y que el contenido cambie según las acciones del usuario.

Elementos y tipos principales

Elemento o tipoDefinición y uso
Script internoEl código se escribe entre las etiquetas <script> y </script>, normalmente al final del body o con defer en head.
Archivo externoSe utiliza <script src='app.js' defer></script>. Facilita organizar y reutilizar el código.
EventoEs una acción, como click, input, submit o change, a la que JavaScript puede responder.
Buenas prácticasSeparar HTML, CSS y JS; usar nombres claros; validar entradas y evitar código duplicado.

Ejemplo de código

Este ejemplo muestra cómo se utiliza el tema en JavaScript. Puedes copiarlo y probarlo en un archivo HTML.

<!-- En el HTML -->
<h2 id="saludo">Texto original</h2>
<button id="cambiar">Cambiar texto</button>

<script>
document.getElementById("cambiar").addEventListener("click", function() {
    document.getElementById("saludo").textContent = "JavaScript está funcionando";
});
</script>

Ejemplo interactivo

Presiona el botón para cambiar este texto.

Recuerda: guarda tus archivos con extensión .html y abre el archivo en un navegador para ejecutar los ejemplos.
