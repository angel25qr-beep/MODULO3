CSS Y DISEÑO

¿Qué es CSS?

CSS significa Cascading Style Sheets. Se utiliza para darle diseño y apariencia a las páginas web.

¿Para qué sirve?

  • Cambiar colores.
  • Cambiar tamaños.
  • Cambiar tipos de letra.
  • Modificar fondos.
  • Dar diseño a tablas.
  • Dar estilo a enlaces y botones.

Selectores

Selector Ejemplo Uso
Etiqueta p Aplica estilos a los parrafos.
Clase .título Aplica estilos a elementos con una clase.
ID #principal Aplica estilos a un elemento específico.

Unidades de medida

  • px - píxeles
  • % - porcentaje
  • em - tamaño relativo
  • rem - tamaño relativo a la raíz
  • vw - ancho de la ventana
  • vh - alto de la ventana

Teoría del color

Los colores permiten mejorar la apariencia de una página web y ayudan a transmitir diferentes sensaciones.

Color Ejemplo de uso
Rojo Advertencias o elementos importantes.
Azul Confianza y tranquilidad.
Verde Naturaleza o seguridad.
Amarillo Atención y energía.
