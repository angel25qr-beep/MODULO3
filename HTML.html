HTML

¿Qué es HTML?

HTML significa HyperText Markup Language. Es el lenguaje utilizado para crear y estructurar el contenido de las páginas web.

¿Para qué sirve?

HTML sirve para organizar textos, imágenes, enlaces, tablas, listas, formularios y otros elementos dentro de una página web.

Etiquetas básicas

Etiqueta Función
h1 Crear un título principal.
p Crear un párrafo.
img Insertar una imagen.
a Crear un hipervínculo.
table Crear una tabla.
ul Crear una lista desordenada.
h2 Crear subtítulos.
br Insertar un salto de línea.
strong Resaltar texto importante.
form Crear formularios.
input Permitir ingresar datos.
