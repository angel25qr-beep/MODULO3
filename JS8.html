8. Funciones en JavaScript

¿Qué es?

Una función es un bloque de código diseñado para realizar una tarea. Puede recibir datos mediante parámetros y devolver un resultado con return.

¿Para qué sirve?

Las funciones permiten reutilizar instrucciones, evitar repeticiones, dividir un problema en partes pequeñas y organizar mejor el programa.

Elementos y tipos principales

Elemento o tipoDefinición y uso
functionPalabra reservada para declarar una función tradicional.
ParámetroVariable escrita en la definición que recibe un dato.
ArgumentoValor concreto que se envía al llamar la función.
returnDevuelve un resultado y termina la ejecución de la función.
LlamadaInstrucción que ejecuta la función usando su nombre y paréntesis.

Ejemplo de código

Este ejemplo muestra cómo se utiliza el tema en JavaScript. Puedes copiarlo y probarlo en un archivo HTML.

function sumar(numero1, numero2) {
    return numero1 + numero2;
}

let resultado = sumar(8, 5);
document.write("El resultado es: " + resultado);

Ejemplo interactivo

Recuerda: guarda tus archivos con extensión .html y abre el archivo en un navegador para ejecutar los ejemplos.
