7. Método DOM

¿Qué es?

DOM significa Document Object Model (Modelo de Objetos del Documento). El navegador representa el documento HTML como una estructura de objetos que JavaScript puede consultar y modificar.

¿Para qué sirve?

El DOM permite cambiar textos, atributos, estilos y elementos; también permite crear o eliminar contenido y responder a eventos.

Elementos y tipos principales

Elemento o tipoDefinición y uso
getElementById()Busca el elemento que tiene un id específico.
querySelector()Devuelve el primer elemento que coincide con un selector CSS.
querySelectorAll()Devuelve una colección de todos los elementos que coinciden.
textContentLee o cambia el texto de un elemento.
innerHTMLLee o cambia el contenido HTML interno. Debe usarse con cuidado si el contenido proviene de usuarios.
stylePermite modificar estilos directamente.
addEventListener()Registra una función que se ejecuta cuando ocurre un evento.

Ejemplo de código

Este ejemplo muestra cómo se utiliza el tema en JavaScript. Puedes copiarlo y probarlo en un archivo HTML.

const titulo = document.getElementById("titulo");
titulo.textContent = "Nuevo título";
titulo.style.color = "blue";

const parrafos = document.querySelectorAll(".nota");
parrafos.forEach(function(p) {
    p.style.backgroundColor = "#e2edf8";
});
