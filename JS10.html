10. Prompt en JavaScript

¿Qué es?

prompt() es un método del objeto window que muestra un cuadro de diálogo para pedir al usuario que escriba un dato. Devuelve el texto ingresado o null si se cancela.

¿Para qué sirve?

Se utiliza para solicitar datos sencillos, como un nombre o una cantidad. El resultado normalmente debe convertirse si se necesita realizar operaciones matemáticas.

Elementos y tipos principales

Elemento o tipoDefinición y uso
prompt(mensaje)Muestra el mensaje y permite escribir una respuesta.
Valor devueltoDevuelve una cadena de texto o null si el usuario cancela.
Number()Convierte el texto recibido a número para realizar cálculos.
ValidaciónConviene comprobar que el usuario no haya cancelado ni dejado el campo vacío y que el dato sea válido.

Ejemplo de código

Este ejemplo muestra cómo se utiliza el tema en JavaScript. Puedes copiarlo y probarlo en un archivo HTML.

let nombre = prompt("¿Cómo te llamas?");

if (nombre !== null && nombre.trim() !== "") {
    alert("Hola, " + nombre);
} else {
    alert("No escribiste un nombre.");
}

let edadTexto = prompt("¿Cuántos años tienes?");
let edad = Number(edadTexto);

if (edadTexto !== null && edadTexto.trim() !== "" && Number.isFinite(edad)) {
    alert("El próximo año tendrás " + (edad + 1));
}
