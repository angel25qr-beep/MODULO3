3. Tipos de operadores

¿Qué es?

Los operadores son símbolos o palabras que permiten realizar operaciones con uno o más valores, llamados operandos. Se utilizan para calcular, comparar, asignar y combinar condiciones.

¿Para qué sirve?

Los operadores ayudan a resolver operaciones matemáticas y a tomar decisiones dentro de un programa.

Elementos y tipos principales

Elemento o tipoDefinición y uso
Aritméticos+ suma; - resta; * multiplicación; / división; % residuo; ** potencia; ++ aumenta uno; -- disminuye uno.
Asignación= asigna; += suma y asigna; -= resta y asigna; *= multiplica y asigna; /= divide y asigna.
Comparación=== igualdad estricta; !== diferencia estricta; > mayor; < menor; >= mayor o igual; <= menor o igual. Devuelven true o false.
Lógicos&& significa Y; || significa O; ! significa negación. Se usan para combinar condiciones.
ConcatenaciónEl operador + también une cadenas de texto.
Condicional?: permite elegir un valor según una condición.

Ejemplo de código

Este ejemplo muestra cómo se utiliza el tema en JavaScript. Puedes copiarlo y probarlo en un archivo HTML.

let a = 10;
let b = 3;
document.write("Suma: " + (a + b) + "<br>");
document.write("Residuo: " + (a % b) + "<br>");
document.write("¿a es mayor que b?: " + (a > b) + "<br>");
document.write("¿Ambos son positivos?: " + (a > 0 && b > 0));

Ejemplo interactivo

Recuerda: guarda tus archivos con extensión .html y abre el archivo en un navegador para ejecutar los ejemplos.
