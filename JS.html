JAVASCRIPT 1 · INTRODUCCIÓN

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite crear comportamiento e interactividad en páginas web. Se ejecuta en el navegador y también puede utilizarse en otros entornos, como servidores.

¿Para qué sirve?

  • Responder a clics y acciones del usuario.
  • Validar formularios antes de enviarlos.
  • Realizar cálculos y procesar datos.
  • Cambiar textos, imágenes y estilos.
  • Crear menús, juegos y aplicaciones web.

HTML, CSS y JavaScript

TecnologíaFunciónEjemplo
HTMLEstructura el contenido.Títulos, párrafos y botones.
CSSDa presentación y diseño.Colores, tamaños y espacios.
JavaScriptAgrega comportamiento.Mostrar un mensaje al pulsar un botón.

Características principales

  1. Es dinámico: el tipo de dato se determina durante la ejecución.
  2. Es sensible a mayúsculas y minúsculas.
  3. Permite programación orientada a objetos y funcional.
  4. Puede manipular el DOM para modificar la página.
  5. Cuenta con operadores, estructuras de control y funciones.

Primer ejemplo

El siguiente código declara variables y muestra un mensaje. Puedes probarlo con el botón.

El resultado aparecerá aquí.

let nombre = "Ángel";
document.write("Hola, " + nombre);
