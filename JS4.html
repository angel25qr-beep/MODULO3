4. Conversión de datos y estructuras de control

¿Qué es?

La conversión de datos consiste en transformar un valor de un tipo a otro, por ejemplo, de texto a número. Las estructuras de control determinan qué instrucciones se ejecutan y cuántas veces.

¿Para qué sirve?

Sirven para interpretar correctamente los datos ingresados y para que el programa tome decisiones o repita instrucciones.

Elementos y tipos principales

Elemento o tipoDefinición y uso
Number(valor)Convierte un valor a número. Por ejemplo, Number('25') produce 25. Si no puede convertirlo, devuelve NaN.
parseInt(valor)Obtiene un número entero desde el inicio de una cadena.
parseFloat(valor)Obtiene un número que puede incluir decimales.
String(valor)Convierte un valor a texto.
Boolean(valor)Convierte un valor a true o false.
if / elseEjecuta un bloque si una condición es verdadera y otro si es falsa.
for / while / do...whilePermiten repetir instrucciones mientras se cumplan las condiciones correspondientes.

Ejemplo de código

Este ejemplo muestra cómo se utiliza el tema en JavaScript. Puedes copiarlo y probarlo en un archivo HTML.

let texto = "18";
let numero = Number(texto);

if (numero >= 18) {
    document.write("Es mayor de edad");
} else {
    document.write("Es menor de edad");
}

for (let i = 1; i <= 3; i++) {
    document.write("<br>Vuelta " + i);
}

Ejemplo interactivo

Recuerda: guarda tus archivos con extensión .html y abre el archivo en un navegador para ejecutar los ejemplos.
