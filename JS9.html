9. Tipos de funciones

¿Qué es?

En JavaScript existen distintas formas de definir funciones. Se pueden declarar con function, guardar en variables como expresiones, escribir como funciones flecha o utilizar funciones anónimas como callbacks.

¿Para qué sirve?

Conocer las formas de función ayuda a elegir la sintaxis adecuada y a organizar el comportamiento de una aplicación.

Elementos y tipos principales

Elemento o tipoDefinición y uso
DeclaradaSe define con function nombre() {}. Puede llamarse antes de su declaración por el mecanismo de hoisting.
ExpresiónSe guarda una función en una variable, por ejemplo const saludar = function() {}.
FlechaSe escribe con =>. Es una forma breve y no crea su propio this.
AnónimaNo tiene nombre propio; puede usarse como argumento o asignarse a una variable.
CallbackFunción que se pasa a otra función para que sea ejecutada posteriormente.
Autoinvocada (IIFE)Función que se ejecuta inmediatamente después de definirse.

Ejemplo de código

Este ejemplo muestra cómo se utiliza el tema en JavaScript. Puedes copiarlo y probarlo en un archivo HTML.

function tradicional() {
    return "Función declarada";
}

const expresion = function() {
    return "Función expresión";
};

const flecha = () => "Función flecha";

document.write(tradicional() + "<br>");
document.write(expresion() + "<br>");
document.write(flecha());

Ejemplo interactivo

Recuerda: guarda tus archivos con extensión .html y abre el archivo en un navegador para ejecutar los ejemplos.
